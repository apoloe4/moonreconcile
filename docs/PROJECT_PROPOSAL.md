# MoonReconcile：纯 MoonBit 集合差异同步基础库

> 申报书初稿：请参赛者理解实现、核对事实并自行润色；不自动提交报名。

**项目简介：** 面向双方拥有大量相同记录、差异较少的场景，以可逆集合摘要恢复新增和缺失 ID，减少全量清单传输。提供可嵌入应用的 MoonBit 原生基础库。

**项目方向与通用性：** 分布式同步与概率数据结构。核心接口独立于网络、数据库和 UI，可接入缓存、备份、对象索引及离线同步系统。

**预期场景一：** 边缘节点与中心缓存交换快照摘要，恢复缺少对象 ID，按需拉取实际内容并在应用事务中更新索引。

**预期场景二：** 备份客户端与远端对象清单比较分区指纹，仅交换变化分区摘要，确定需补传或复核的数据块。

**预期场景三：** 离线设备重新连接后冻结双方记录版本，恢复事件 ID 差异；摘要容量不足时扩大摘要，超过预算时回退全量清单。

**核心功能：** 三分带 IBLT 插入、删除、相减和正负差异恢复；精确去重集合；快照与分区清单编解码；分块接收；资源预算、容量重试、快照失效检测及原子同步计划校验。

**技术路线：** 以计数、ID 异或和校验摘要判断可恢复单元，通过 peeling 恢复差异；按 scope/epoch 固定快照，按分区指纹缩小交换范围，以总体指纹核验结果。概率碰撞和恶意节点处理边界明确。

**现有基础与计划：** 0.1.0 已实现上述核心路径、可运行示例、异常输入和生成式测试、CI 配置及中文文档。后续重点开展外部应用接入、不同差异率下的性能评估和 Mooncakes 发布，而非扩大无关功能。

**原创与参考：** 本项目依据 Goodrich/Mitzenmacher 的 IBLT 论文独立实现，不主张算法原创，不是现有库移植；没有复制竞品代码。SplitMix64 混合与 CRC 来源见 NOTICE.md。代码和文档使用 AI 辅助，需由参赛者理解和维护。

**查重说明：** 2026-10-04 查询 iblt/ibf/minisketch 未找到直接包；源码核查 sketch、moon-sketch-kit、moon-frequency-sketch、loci 四个相邻版本，区别在于有方向的差异 ID 恢复与同步计划协商。结果不是官方审核保证，详见 docs/DUPLICATION_REVIEW.md。

**范围限制：** 仅同步 UInt64 ID 集合，不实现对象内容下载、认证网络、持久化数据库或业务冲突解决；实验版本需进一步真实负载验证。
